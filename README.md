# pi-top Robotics

Python recipes and lessons for the [pi-top](https://pi-top-pi-top-python-sdk.readthedocs-hosted.com/en/stable/getting_started.html) robotics kit.

## Run

```bash
pip install -r requirements.txt
python Recipes/LED.py
```

## Notes

- `Recipes/` – one script per sensor/actuator (LED, buzzer, camera, ultrasonic, motors, rover)
- `Robotics-101-Rover-vision/` – numbered lesson sequence (1zero → 10Mission)
- `Builds/` – projects such as the catapult
